About

Hi, I'm wolfawwent. I build small games, editor plugins and interactive things. I like pixel art, idle mechanics, shaders and making tools that make other people's work faster.

This site is a living playground — the background you see is a live GLSL shader, and the 3D section runs on Three.js. Everything is plain HTML / CSS / JS.
